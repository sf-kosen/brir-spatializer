## 1. 確認した現状コードの前提

- `generate_cinema.py`
  - `Room` は 6 面（`x0`,`x1` 側壁、`y0` スクリーン壁、`y1` 後壁、`z0` 床、`z1` 天井）の帯域別吸音率。リスナーは −y（スクリーン側）を向く。
  - 初期部は direct + 80 ms（`render_speaker(early_after_direct=0.080, crossfade=0.020)`）まで鏡像法、以降は KU100 の拡散場統計に合わせた拡散テール。テール包絡は `4πc/(V·Q)`、減衰は Eyring RT60（空気吸収込み）。
  - IR 長は `min(rt60.max()*1.5, 3.0) + 0.1` s（L546）。
  - 校正（L563–574）: 各フィードの無指向「測定マイク」応答を `target_curve`（既定 `xcurve-small`）に EQ し 500 Hz–2 kHz でレベル合わせ。`surround_feeds` は −3 dB。`bass_feeds`（LFE）は 25–120 Hz で flat。
  - 遅延（L578–582）: `screen_arrival = first_arrival["C"]`。サラウンドのみ C の到達に揃え、**その他のフィードは一律 `-(C到達 - 2 ms)` だけ前にずらす**。
  - 音色補正（L481–501）: グローバル `PROGRAMME_WEIGHTS = {C:.5, L:.2, R:.2, Ls:.05, Rs:.05}` で加重したバイノーラル応答を 8 kHz まで平坦化（±6 dB）。
  - 正規化（L613–618）: `binaural["C"]` のピンク加重エネルギーを片耳 0.5 に。
  - レポート（L632–640）: `omni["C"]` の Schroeder T30、`binaural["C"]` の広帯域 IACC（early 0–82 ms / late 82 ms–1 s）。
  - メタデータ: `"format": "brir-cinema/1"`、出力ファイル名 `cinema.json`、既定出力 `Generated/cinema/<preset>`。
- アプリ（`app/src/MainComponent.cpp`）
  - `readCinema()` は `format == "brir-cinema/1"` を必須とし、`feeds[].name` を `Renderer::kFeedNames`（L C R Ls Rs LFE）に照合。未知キーは無視。WAV は 2ch・10 秒以内。
  - 一覧は `findCinemaRoot()` が見つけた `Generated/cinema` 直下の `*/cinema.json` のみ。ファイル選択ダイアログのフィルタも `cinema.json`。
  - LFE が無いセットでは `cinemaHasLfe_ = false` → サブウーファー UI 無効、ベースマネジメント off、メインは全帯域。**LFE を出さなければアプリ側の対応は不要。**
- エンジン: `Renderer` は L C R Ls Rs + LFE 固定。IR が空のパスは無音。IR 長の制約は実質なし（ローダーの 10 s 制限のみ）。
- `tools/render_file`: 独自の `loadCinema()`（format を見ない）。**残響テール用のパディングが `rate * 1.5` 固定**で、2 s 級のホール残響は書き出し時に切れる。
- `tools/output_probe` は `tools/common/cinema_loader.h` を使用。`render_file` は同等コードを重複保持。
- アップミキサー（`engine/src/upmixer.cpp`）が Ls/Rs に送るもの（§3.4 で詳述）:
  1. アンビエンス成分（L/R 間で無相関な成分）の `σ`（既定 0.3）分のエネルギー。左右それぞれの位相のまま Ls←左, Rs←右。
  2. **逆相のプライマリ成分**（`back = sqrt(1 - front²)`）。100 Hz 以下はそのまま、100–200 Hz でクロスフェードし、それ以上は Lauridsen 相補コム（10 ms 遅延、Ls = (M+M_d)/√2, Rs = (M−M_d)/√2）で非相関化。
  3. ビン単位でエネルギー保存。

参考: 現行映画館は 16 × 24 × 8 m（3,072 m³）、Eyring 1 kHz 0.45 s、63 Hz 0.80 s → IR 長 1.3 s。

## 2. 室モデル

### 2.1 寸法

**推奨: W 20 m × L 44 m × H 18 m、V = 15,840 m³**

- 実在の優良シューボックス: Wiener Musikverein（約 19.8 m 幅、V ≈ 15,000 m³、満席 RT ≈ 2.0 s、1,680 席）、Boston Symphony Hall（約 23 m 幅、V ≈ 18,750 m³、満席 RT ≈ 1.9 s）、Amsterdam Concertgebouw（幅 28 m、V ≈ 18,800 m³）。
- 幅 20 m を選ぶ理由: このモデルは鏡像法のみで、バルコニー前面・ソフィットからの早期側方反射が無い。側方反射の到達を早めるには幅を狭くするしか手段がない。23 m 幅だと中央線席で C 音源の初回側壁反射が +33 ms になり、ITDG ≤ 20 ms（Beranek）から大きく外れる。20 m なら L/R 音源は ~12 ms、C は ~26 ms（§2.3）。
- 座標系は映画館と同じ: `y=0` がステージ端の壁（オルガン・合唱席側）、リスナーは −y を向く、`x=0` がリスナーから見て左。
- ステージ: `y = 0–12 m`、全幅（Musikverein と同様、ステージが同じ箱の中にある）。床高 1.0 m（形状としてはモデル化せず、音源高さに反映するのみ）。客席は `y = 12–44 m`（32 m、平土間フラット）。

- **注意**: Beranek の聴衆吸音率は Sabine 式で校正された値。同じ値を Sabine に入れると 1 kHz で約 2.1 s になる。本設計は「このコードの Eyring で目標 RT に着地する値」として選んでおり、文献値との比較は Sabine/Eyring の差（約 10%）を考慮すること。
- 臨界距離（1 kHz、Q = 1.6）: r_c = 0.057 √(QV/T) ≈ **6.6 m**。映画館（Q ≈ 10 のホーン、T = 0.45 s）は ≈ 15 m で中央席がほぼ r_c 上にあるのに対し、ホールの両プリセットは r_c の 1.5–3 倍の距離にあり、残響音優勢となる。これはホールとして正しい。

### 2.4 初期部/後期部の境界と IR 長

- 初期窓: ミキシングタイム ≈ √V ms ≈ 126 ms に合わせ、**`early_after_direct = 0.120`、`crossfade = 0.030`**（映画館は 0.080 / 0.020 のまま）。鏡像数は到達半径 ≈ 72 m で約 100 個と軽い。
- IR 長: 既存式 `min(1.5·RT_max, 3.0) + 0.1` をこのホールに当てると RT_max = 2.33 s（63 Hz）→ **3.1 s**。63 Hz で −77 dB、1 kHz で −95 dB まで減衰しており、実はこのホールでは既存の上限で実害はない。ただし係数と上限は会場パラメータにし、コンサートは上限 4.0 s とする（より大きいホールや BR を上げた代替案に備える）。
- 映画館の 1.3 s に対して約 2.4 倍。コスト見積もりは §5.9。

## 3. 音源配置

### 3.1 フィードとステージの対応

フィードはオーケストラのパートではなく、**ステレオ録音をアップミックスしたパン位置**である。一般的なオーケストラ録音（Decca tree / ORTF 等、アメリカ式配置）では:

| フィード | 主に載る内容 | ステージ上の解釈 |
|---|---|---|
| L | 第 1・第 2 ヴァイオリン、ハープ | 下手（客席から見て左）前方 |
| C | 木管、金管・ティンパニの中央成分、独奏者、合唱・オルガンの中央成分 | 中央 |
| R | ヴィオラ、チェロ、コントラバス | 上手（右）前方 |
| Ls/Rs | 録音に含まれるホール残響・拍手・逆相成分 | ステージではない（§3.4） |

合唱・オルガンは独立フィードを持たず、録音のパンに従って L/C/R に含まれる。専用の音源点を足すことは §3.2 末尾の理由で v1 では行わない。

### 3.2 位置

ステージ床高 1.0 m + 着席奏者の楽器高 ≈ 1.1 m → 音源高 2.1 m。

| フィード | 位置 (x, y, z) [m] | 向き（aim） | highpass |
|---|---|---|---|
| L | (4.0, 9.0, 2.1) | (10, 28, 3.0) 客席中央・頭上 | 20 Hz |
| C | (10.0, 8.0, 2.4) | 同上 | 20 Hz |
| R | (16.0, 9.0, 2.1) | 同上 | 20 Hz |

設計判断:

- **L/C/R はほぼ等距離に置く。** 実際のオーケストラでは木管はひな壇上で弦より 3 m ほど奥だが、C を (10, 6, 2.6) に置くと stalls_center で L/R が C より 5.8 ms 早く届く。アップミキサーは L–C 間をペアワイズでパンするので、同じ信号が 5.8 ms 差で 2 点から届き、先行音効果で像が L に引っ張られ、コムフィルタも生じる（実際の奏者は互いに無相関なので問題にならないが、アップミックスでは問題になる）。C を y = 8.0 に置くと stalls_center で L/C 到達差 ≈ 0、stalls_front では C が 2.3 ms 先行する（映画館 `front_large` と同じく中央側に引かれる方向で、許容できる）。
- **向きはリスナーではなく客席上の固定点**（映画館のスクリーン用スピーカーは `aim = listener`）。奏者は特定の席を狙わないので、座席プリセットが変わっても音源は不変とする。弦楽器の高域が上方へ放射されることも考え、aim を 3.0 m の高さにしている。
- L/R の高さは対称に揃える（チェロは実際には少し低いが、センターのバランスを優先）。
- 代替案（非推奨）: 1 フィードを複数点で構成してセクションの広がりを出す。パイプラインは同一信号をコヒーレント加算するため、数 m 離れた点が並ぶとラインアレイのようなコムフィルタになる。セクションの広がりは L/C/R 間のパンと残響で十分表現できる。

### 3.3 指向性（楽器 vs 映画館スピーカー）

既存の `((1+cos)/2)^p`、`p = (Q−1)/2` モデルをそのまま使う。

| | 63 | 125 | 250 | 500 | 1k | 2k | 4k | 8k | 16k |
|---|---|---|---|---|---|---|---|---|---|
| 映画館スクリーン（ホーン、現行） | 1.0 | 1.5 | 2.5 | 5 | 10 | 16 | 20 | 25 | 30 |
| **ステージ L/C/R（推奨）** | 1.0 | 1.0 | 1.1 | 1.3 | 1.6 | 2.0 | 2.5 | 3.0 | 3.0 |
| C 代替（金管寄り） | 1.0 | 1.0 | 1.2 | 1.5 | 2.0 | 2.5 | 3.5 | 4.0 | 4.0 |
| **Ls/Rs 放射体（推奨）** | 1.0 | 1.0 | 1.0 | 1.2 | 1.5 | 1.8 | 2.0 | 2.0 | 2.0 |

根拠: J. Meyer "Acoustics and the Performance of Music" によれば、弦楽器は 500 Hz 以下でほぼ無指向、1–2 kHz 以上で表板の法線（上方・側方）に偏る。金管はベル軸方向に強い（単体なら 4 kHz で Q 5–10）が、セクション平均ではベルの向きがばらつく。木管はトーンホール放射でローブが多い。セクション平均を取るとホーンスピーカーよりはるかに無指向に近い。結果として音響パワーに対する残響の比率が映画館より大きく、低 Q がホールらしい「包まれ感」を生む。stalls_front での軸外角は約 18° で、4 kHz の減衰は 0.2 dB 未満（座席による音色差は主に室内音響から来る）。

### 3.4 Ls/Rs：ステージ後方ではなく「ホール・アンビエンス放射体」

アップミキサーが Ls/Rs に送るものは §1 のとおり **(1) 録音中のアンビエンス（無相関成分）、(2) 逆相プライマリ成分（200 Hz 以上は相補コムで非相関化）** である。いずれもステージ上の楽器の直接音ではない。

ステージ後方（例: 舞台奥の両隅、オフステージ金管の位置）に Ls/Rs を置くと次の問題がある:

1. 録音のアンビエンスが前方から出て、さらにホール残響が掛かる。残響が二重になるうえ前方に寄り、包まれ感（LEV）はホール自身の残響からしか得られない。
2. Lauridsen 相補コムは、**大きく離れた 2 方向から別々の耳に届くこと**を前提に非相関化している。舞台奥の 2 点はリスナーから見てほぼ同じ方向（±8° 程度）なので、両耳に Ls+Rs がほぼ同じ比率で届く。コムが打ち消し合ってモノラル成分に戻り、非相関化が無意味になる。
3. 逆相成分の多くはスペースドマイクの位相差や残響なので、空間情報として扱うべきで、ステージ上の音源にするのは不適切。

**推奨（A）: 客席の側壁・後壁高所に分散配置した低指向性放射体**（物理的なホールにスピーカーは無いが、目的は「録音のアンビエンスを、実ホールで残響が来る方向から返す」こと）

| 配列 | 位置 [m] | aim | 
|---|---|---|
| Ls | 側壁 x = 0.5、y ∈ {20, 26, 32, 38}、z = 7.0（第 1 バルコニー前面の高さ）+ 後壁 (6.0, 43.5, 7.0) | 側壁: (15, y, 1.2)、後壁: (6, 22, 1.2) |
| Rs | 鏡像（x = 19.5、後壁 (14.0, 43.5, 7.0)） | 鏡像 |

- 各配列 5 台、1 台あたりの振幅 1/√5（配列合計の音響パワーがステージ音源 1 個と等しい）。highpass 40 Hz。
- 時間整列: **配列の初到達 = ステージ初到達 + 20 ms**（§4.3）。stalls_center では最寄り放射体（11.1 m、32.4 ms）を 40.2 ms 遅らせ、stalls_front では 16.4 ms 遅らせる。
- 代替（B）: Ls/Rs は鏡像（初期反射）を持たず、拡散テールのみ（ステージ初到達 + 20 ms からフェードイン）。放射体の定位が原理的に起こらない一方、側方からの初期エネルギー（ASW）が出ない。A で放射体が「壁のスピーカー」として聞こえた場合の退避策として `--surround-mode diffuse` で実装しておく。

### 3.5 LFE

**推奨: コンサートセットは LFE を出力しない。**

- ホールにサブウーファーは無い。ステージ音源は 20 Hz highpass で全帯域を放射し、低域の残響（63 Hz 2.3 s）もそのまま含む。
- アプリは LFE の無いセットでベースマネジメントを自動的に無効化し、サブウーファー UI もグレーアウトする（`applyBassManagement()`、`render_file` も同様）。エンジン変更は不要。
- アプリのサブ既定値 +4 dB は映画館の慣習なので、ホールに持ち込まない。低域を足したい場合は、既存のヘッドホン EQ の低域シェルフを使う。
- 非推奨案: ステージ床中央に低域音源を置いて LFE を生成する。80 Hz 以下の方向はほとんど知覚されず得るものがないうえ、「サブ +4 dB」が既定で効いてしまう。

## 4. 校正（映画館との違い）

### 4.1 目標カーブ: 室内 EQ をしない（物理校正）

映画館の各フィードを X-curve に EQ するのは「室を補正する」行為である。ホールでは室の音色（低域上昇、空気による高域減衰）こそが求める音なので、**フィード単位の EQ・レベル合わせは行わない**（新しい `calibration = "physical"`）。

本設計の定常応答（stalls_center、500 Hz–2 kHz 基準、RT 比 + Q 比からの概算）は 125 Hz で約 +2 dB、4 kHz で約 −4 dB、8 kHz で約 −6.5 dB。`xcurve-small` や `flat` で EQ すると、低域を 2 dB 削り、高域を 3–6 dB 持ち上げることになり、BR 1.1 の温かさと距離感を消してしまう。

- 楽器の録音は「客席方向の on-axis で収録された」とみなし、音源の on-axis 応答はフラット（既存スピーカーモデルと同じ扱い）。
- 各ステージ音源のゲインは 1.0（物理距離減衰のみ）。Ls/Rs 配列は 1/√N。
- `targetCurve` メタデータは `"none"`。

### 4.2 フィードのレベル関係

- **−3 dB サラウンド規則は使わない。** 映画館の −3 dB はフィルムミックスの再生規格（サラウンドアレイの校正レベル）に由来する。今回の Ls/Rs はアップミキサーが L/R から**エネルギー保存で取り分けた**アンビエンス（`ambFront = √(1−σ)`, `ambBack = √σ`）なので、ステージと同じ音響パワーで返すのがエネルギー的に一貫する（0 dB）。量はアプリの「サラウンド」スライダー（σ）で調整する。
- 代替: 試聴で残響過多なら Ls/Rs を −3 dB（`feed_level_db`）にする。
- ステージ L/C/R は等パワー（ゲイン 1）。等距離配置なので、座席での測定レベルも ±0.5 dB 以内に揃う。

### 4.3 遅延整列

- **ステージ音源は整列しない。** 映画館で行う「サラウンドをスクリーンの到達に合わせる」処理は、物理的に離れたスピーカー群を一つの音場として揃えるための電気的補正である。ホールでは L/C/R の到達差そのもの（stalls_front で C が 2.3 ms 先行）がその席の現実なので、触らない。
- 時間原点: **L/C/R の最早到達 − 2 ms**（既存は C 固定）。
- Ls/Rs: 初到達をステージ初到達 + **20 ms** に置く。根拠:
  - 実ホールの側方反射は直接音の 10–40 ms 後に到達し、この範囲は ASW/LEV に寄与するが音楽の定位を奪わない（音楽のエコー閾値は 50 ms 以上）。
  - 0 ms（映画館式）だと、逆相プライマリのトランジェントで像が側方に引っ張られる。
  - 録音のアンビエンスは録音内ですでに直接音より遅れているので、+20 ms で二重に遅れても不自然にならない。
  - 代替: +10 ms（より密着）/ +40 ms（より分離）。試聴で決める。

### 4.4 全体音色（timbre）

既存の `neutral` は「部屋 + X-curve + 頭部」の傾きをまとめて 8 kHz まで平坦化する。ホールでは部屋の傾きを残したいので、新モードを追加する。

**`timbre = "hall"`（コンサート既定）**: 番組加重（§5.4）したバイノーラル応答（両耳平均、1/3 oct 平滑化）を、同じ加重の**無指向測定応答に一致させる**共通 FIR（±4 dB、100 Hz–16 kHz、範囲外は保持）。拡散音場/正面平均で EQ した HRIR の残留色付け（主に 2–10 kHz）だけが取れ、座席で無指向マイクが測る音色、つまりホールの音色がヘッドホンに出る。

- 代替: `neutral`（映画館と同じく 8 kHz まで平坦）。「こもる」という不満が出たときの選択肢。
- 代替: `none`（何もしない）。

### 4.5 全体ゲイン正規化 ― 何が壊れ、何を一般化するか

現行 `generate()` の C 依存箇所:

| 箇所 | 現状 | コンサートでの影響 | 対応 |
|---|---|---|---|

## 7. リスクと未決事項（要判断）

1. **シューボックス単独の鏡像法**: バルコニー前面・ソフィット・バルコニー下の席・彫像や格天井による拡散が無い。早期側方反射が少なく、全反射が鏡面的。ITDG と IACC_E が実ホールより悪く出やすい。対策候補は面ごとの散乱係数（鏡面エネルギーの s をテール側へ早期移送）と、バルコニー前面を表す追加の離散反射。どちらもフェーズ 3。
2. **平行側壁のフラッター**: 20 m 間隔、往復 117 ms。初期窓 120 ms 内では 1–2 往復なので影響は小さいはずだが、試聴で確認する。
3. **カップルドボリューム・ステージ音響反射板・オルガン室**: 単一の指数減衰のみで、二重勾配は再現しない。対象外とする。
4. **seat-dip 効果**: 客席上をかすめる伝搬で 100–250 Hz に 10 dB 前後の落ち込みが出る現象を再現しない（床反射は聴衆 α の鏡面反射として扱われるだけ）。平土間席に固定ノッチを入れるか？ → 実ホール感は増すが「痩せた低域」と感じられる恐れがある。**要判断。**
5. **ステージ床の扱い**: 音源は z = 2.1 m だがモデルの床は z = 0 の単一面（合成 α）。ステージ板の強い床反射は弱めに出る。軽微。
6. **吸音の空間分布**: 吸音が床に集中しているので、実際は Eyring の拡散仮定より長い残響・非指数減衰になりうる。ただしテールは Eyring で合成しているので、モデル内部では自己整合する（現実性の問題であって不具合ではない）。
7. **録音側の残響との二重化**: 市販のオーケストラ録音は 1.5–2.5 s 相当のホール残響をすでに含む。ホール BRIR を重ねると「洗面器」的になりうる。想定している主な素材は何か？（ドライなポップス/映画音楽か、クラシック録音か。）後者が主なら、小ホール（V ≈ 6,000 m³、RT ≈ 1.5 s、室内楽向け）のプリセットを優先すべきかもしれない。**要判断。**
8. **Ls/Rs の意味付け**: 放射体は物理的なホールには存在しない。A（放射体）と B（拡散テールのみ）のどちらを既定にするかは試聴次第。
9. **中央線の対称性**: IACC_E が高めに出る。オフセット席を追加プリセットにするか？
10. **IR 長と CPU**: 映画館の 2.4 倍。ベンチで遅延ブロックが出る環境があれば `maxBlockSize` を上げるか、テールを短くする（IR 長係数を 1.3 にすると 3.1→2.6 s、63 Hz で −65 dB）。
11. **音色の既定**: `hall`（ホールの高域減衰を残す）か `neutral`（映画館と同じ明るさ）か。ヘッドホンで「こもる」という指摘が過去にあった（`neutral` 導入の経緯）ので、**要判断。**
12. **アプリ UI**: 「映画館」→「会場」への改名、コンサート用アップミックス既定値（`upmixDefaults`）を自動適用するか。
13. **座席プリセットの追加**: `balcony_rear` は張り出しのモデル化なしでは不正確。必要か？
14. **数値の未検証**: 本書の RT・C80・G・幾何値は手計算。実装の最初のステップで `eyring_rt60()` を実行し、表と照合すること。

## 8. 理想ホール `ideal`（物理的には存在しない会場）

### 8.1 狙い

§2–§4 のシューボックスは「実在しうるホール」で、そのぶん物理の制約をそのまま受ける。直接音の近さと残響の豊かさは席の位置で引き換えになるし、残響の長さ・量・明るさは容積と空気吸収で決まってしまう。初期反射の方向と時刻は壁の位置で決まり、床・天井の反射やフラッター、低域の室モードも避けられない。

理想ホールは室形状を持たない。**直接音・初期反射・残響テールをそれぞれ部品として指定し、聴感上の指標（C80、LF、IACC、RT、BR）を目標値から逆算する。** 実ホールのプリセットは置き換えず、`Generated/concert/ideal/` として並べて A/B する。

物理的に不可能な点（＝この会場の売り）:

| 項目 | 実ホール（§2–§4、stalls_center） | 理想ホール |
|---|---|---|
| 席の位置と音の関係 | 近いほど明瞭・残響は少なめ、遠いほど豊かだが遠い | 直接音は 8 m 相当の近さ、残響は C80 の目標から量を決める（位置に縛られない） |
| 初期反射 | 壁の位置で決まる。左右対称・床/天井の反射あり・ITDG 12–26 ms | 側方（方位 50–125°、仰角 5–45°）だけに 12 本、左右で**時刻をずらして非対称**。床・天井・正面からの反射なし（コムと IACC 上昇の原因を除く） |
| 反射の質 | 鏡面（同じ波形のコピー） | 1 本ずつを 4 つの微小な副反射に分ける「完全拡散」（吸音による損失なし） |
| 残響の明るさ | 空気吸収で 4 kHz 1.44 s、8 kHz 0.88 s、16 kHz 0.37 s | 空気吸収なし: 4 kHz 1.8 s、8 kHz 1.55 s、16 kHz 1.2 s |
| 低域 | BR 1.11。室モード・フラッターは鏡像法の範囲で発生 | BR 1.19。テールは雑音合成なので室モード・フラッターが原理的に無い |
| 残響の方向 | 拡散（全方位均等） | 側方寄りに重み付けした拡散音場（包まれ感 LEV を強める。§8.4） |
| Ls/Rs | 客席壁の放射体（ホール残響が掛かる） | **残響の掛からない側方の「乾いた」放射体**（録音の残響を二重にしない。§8.5） |

### 8.2 直接音（L/C/R）

- 方向: L +22°、C 0°、R −22°（方位、+ が左）。仰角 +5°（ステージがやや高い）。幅は stalls_center（±19°）と stalls_front（±34°）の間。
- 3 本とも同じ距離・同じ到達時刻。ゲインは 10 m 自由音場に対して +1.9 dB（8 m 相当）。
- 周波数特性: フラット（空気吸収・楽器の指向性による減衰なし）。
- 頭部伝達関数: KU100 の該当方向（既存 `Hrtf.nearest`）。

### 8.3 初期反射

直接音からの相対時刻・方向・レベル（レベルは直接音比）。L/C/R の 3 フィードに**同じパターン**を使う（直接音の到達が揃っているので、L–C 間にパンされた音も 1 つの音源と同じ反射を持つ）。

| # | 時刻 [ms] | 方位 [°] | 仰角 [°] | レベル [dB] |
|---|---|---|---|---|
| 1 | 14 | +62 | 10 | −11.2 |
| 2 | 17 | −58 | 8 | −11.2 |
| 3 | 23 | −75 | 25 | −12.2 |
| 4 | 26 | +80 | 20 | −12.2 |
| 5 | 31 | +105 | 15 | −13.2 |
| 6 | 35 | −100 | 30 | −13.2 |
| 7 | 41 | +50 | 35 | −14.2 |
| 8 | 44 | −120 | 10 | −14.2 |
| 9 | 52 | +125 | 25 | −15.2 |
| 10 | 57 | −65 | 40 | −15.2 |
| 11 | 64 | +90 | 45 | −16.2 |
| 12 | 71 | −90 | 5 | −16.2 |

設計判断:

- **ITDG 14 ms**（Beranek の ≤ 20 ms）。左右の対は 3 ms 前後ずらし、時刻を整数比にしない（櫛形・フラッター感を避ける）。左右のエネルギーは等しいので、センターの像はずれない。
- **正中面（正面・真上・真後ろ）からの反射を置かない。** 正中面の反射は両耳に同じ遅延で届くので、音色にコムが付き IACC も上がる。実ホールでは天井と床が必ずこれを作る。
- 反射の合計エネルギーは直接音の −2.6 dB。
- 帯域特性: 2 kHz までフラット、4 kHz −1 dB、8 kHz −2 dB、16 kHz −3 dB（完全にフラットだと「金属的」に聞こえやすいので、ごく軽い壁の特性だけ残す）。
- **完全拡散**: 各反射を 4 つの副反射（等エネルギー、時刻ずれ 0–1.5 ms、方向ずれ ±8°、seed で固定）に分ける。鏡面のコピーより櫛形の細かい凹凸が減り、反射がひとつの「点」ではなく「面」として聞こえる。代替: 鏡面（副反射 1 つ）。試聴で比較する。

### 8.4 残響テール

- 開始: 直接音 + 20 ms からレイズドコサインで 40 ms かけて立ち上がり、その後は帯域ごとの RT で指数減衰。初期反射とは**重ねて**置く（鏡像法→テールのクロスフェードは無い）。
- RT60（指定値、Eyring ではない）:

| 帯域 | 63 | 125 | 250 | 500 | 1k | 2k | 4k | 8k | 16k |
|---|---|---|---|---|---|---|---|---|---|
| 理想ホール [s] | 2.7 | 2.6 | 2.4 | 2.15 | 2.05 | 1.95 | 1.8 | 1.55 | 1.2 |
| 実ホール（§2.2） [s] | 2.33 | 2.21 | 2.12 | 2.01 | 1.90 | 1.76 | 1.44 | 0.88 | 0.37 |

  T_mid 2.10 s、BR = (2.6 + 2.4) / (2.15 + 2.05) = **1.19**（Beranek の推奨 1.1–1.25 の中央）。高域を完全に平坦（16 kHz まで 2.0 s）にする案は、シューという雑音感と歯擦音のにじみが出やすいので採らない。
- レベル: 立ち上がり直後のエネルギーは帯域間でフラット（低域の RT が長いぶん、低域のエネルギーが自然に増えて温かさになる）。**全体のレベルは mid 帯域の C80 が目標値になるように逆算する**（実ホールでは C80 は RT・容積・距離で決まり、自由に選べない）。
- 目標 C80 = **+1.0 dB**（交響曲の推奨 −1…+1 dB の上端。明瞭さ寄り）。このときの見積もり（エネルギー計算、1 kHz）:
  - テール合計 = 直接音 +3.3 dB。直接音は全エネルギーの −6.1 dB（stalls_center は約 −7.9 dB）。
  - LF（側方エネルギー比、5–80 ms）≈ **0.27**（良いホールの席で 0.15–0.25）。
  - EDT ≈ 1.8 s（直接音が強いぶん RT より短い）。
- 方向分布: `DiffuseField` の統計を、方向に重み w(d) = 1 + κ·y²（y は両耳軸方向の成分、κ = 2）を付けて計算する。側方からのエネルギーの割合が 1/3 から約 0.6 に増える。代替: κ = 0（現行の一様拡散）。
  - 注意: IACC は ±1 ms のずれの中の最大値なので、側方に寄せても IACC_L が下がるとは限らない。狙いは LEV（包まれ感）の方で、IACC は §8.8 の計測で確認する。
  - 不採用: 拡散音場より低い両耳相関（特に 500 Hz 以下）を人工的に作ること。頭の大きさで決まる相関を下回ると、位相が回ったような不快感や頭内定位になりやすい。

### 8.5 Ls/Rs: 残響の掛からない側方放射体

§7-7（録音に元々入っている残響との二重化）への、この会場ならではの対策。

- アップミキサーは録音の残響（L/R 間で無相関な成分）をおもに Ls/Rs に送る。実ホール案ではそこにさらにホールの残響が掛かる。
- 理想ホールでは **Ls/Rs の IR を「残響なし」にする**: 録音の残響は側方から乾いたまま返り、ホールの残響は L/C/R（直接音成分）にだけ掛かる。実在のホールでは「残響の中に置いた無響のスピーカー」は作れないが、BRIR なら作れる。
- 定位対策: 1 方向の点音源だと「横にスピーカーがある」と聞こえるので、Ls は方位 +90°/+110°/+135°（仰角 15°）の 3 方向に分ける。それぞれに独立したベルベットノイズ（長さ 15 ms、まばらな ±1 のパルス列、振幅特性がほぼフラット）を畳み込み、合計エネルギーをステージ音源 1 個と等しくする。Rs は左右反転、ノイズは別の seed。
- 時刻: ステージの直接音 + 20 ms（§4.3 と同じ理由）。
- 代替: 実ホール案と同じ残響付き放射体（`--surround-mode reverberant`）。

部分的な対策である点に注意: 録音の残響のうち L/R で相関の高い成分（低域や、近接マイクに回り込んだ残響）は L/C/R に残るので、そこには引き続き二重に掛かる。

### 8.6 校正・音色・正規化

- 校正: `physical`（§4.1）。LFE なし。
- 音色: `hall`（§4.4）。空気吸収が無いぶん、実ホールの `hall` より明るくなる。
- 番組加重と正規化: 実ホール（§5.4）と同じ。`reference_feed = "C"`。

### 8.7 コード

`generate()`（§5.2）は室（`Room`、鏡像法、Eyring）に依存しているので、2 段に分ける:

1. `render_feeds(venue, hrtf, diffuse, rng) -> (binaural, omni, first_arrival)`: 会場ごとの部分。シューボックスは現行の `render_speaker` を使う。
2. `finalise(venue, binaural, omni, first_arrival, out_dir)`: 共通部分（校正、遅延整列、音色、正規化、レポート、書き出し）。映画館のビット一致（§6.1）はこの分割後も確認する。

新規 `tools/cinema_brir/generate_ideal.py`（`brir_core` を使う）:

- `IdealHall`（dataclass）: 直接音の方向と距離、反射表、`tail_rt60[9]`、`tail_onset_s`、`tail_rise_s`、`c80_target_db`、`lateral_kappa`、Ls/Rs の方向とベルベットノイズの長さ。
- `render_direct()`, `render_reflections()`（副反射の展開を含む）, `render_ideal_tail()`, `render_dry_emitters()`。omni 版も同時に作る（反射はゲインと遅延のみ、テールはモノラル雑音を同じ包絡で）。
- 既存関数の小改造:
  - `DiffuseField(hrtf, length, directions, weights=None)`。重み付きの平均を取るだけで、`weights=None` なら現行とビット一致。
  - `render_tail()` から室依存（`eyring_rt60(cinema.room)`、`4πc/(VQ)`）を外し、`rt60` と帯域ごとの開始レベルを引数で受ける形にする。映画館側は今の値を計算して渡す。
- C80 の逆算: テールを単位レベルで一度描き、omni 応答から mid の C80 を計算し、目標との差を二分法で詰める（テールのレベルは線形なので、2–3 回で収束する）。
- CLI: `python tools/cinema_brir/generate_ideal.py [--c80 1.0] [--kappa 2] [--reflections diffuse|specular] [--surround-mode dry|reverberant] [--seed 1]`。既定の出力先は `Generated/concert/ideal`、表示名は「理想ホール（物理的には存在しない）」。

### 8.8 検証

| 指標 | 目標 | 判定 |
|---|---|---|
| T30（omni） | §8.4 の表 | ±5%（指定値どおりに合成しているので） |
| C80（mid） | +1.0 dB | ±0.2 dB（逆算しているので） |
| EDT | ≈ 1.8 s | 1.6–2.0 s |
| LF | ≈ 0.27 | ≥ 0.2 |
| IACC_E3 | C を含む全フロントフィードで ≤ 0.35 | 実ホール（中央線で C は 0.5–0.7）より大きく下がること |
| IACC_L3 | ≤ 0.2 | κ = 0 と 2 の両方で記録する |
| 直接音の到達 | L/C/R で一致 | ±0.1 ms |

試聴（§6.3 の素材に加えて）:

- `ideal` と `stalls_center` / `stalls_front` の A/B。期待: 前方の明瞭さと残響の包まれ感が同時にある。
- **不自然さのチェック（いちばん重要）**: 「残響プラグインっぽい」（直接音と残響がばらばらに聞こえる）、金属的、位相が回る感じ、頭内定位、側方に穴が空いた感じ。どれかが出たら、反射を `specular`→`diffuse` に、κ を 2→1 に、反射を 1 本だけ真上（仰角 70°、−18 dB）に足す、の順で試す。
- Ls/Rs: `--surround 30` / `60` で、側方に「スピーカーがある」と定位しないこと。残響の多いクラシック録音で、実ホール案より「洗面器感」が減ること。

### 8.9 リスクと要判断

1. **不自然さ**: 物理的に矛盾した組み合わせ（直接音が近いのに残響は豊か）は、耳が「作り物」と判断することがある。目標値はまず控えめ（C80 +1 dB、κ = 2）にし、試聴しながら広げる。
2. **床・天井の反射を消す影響**: 正中面の反射は、前方の像を頭の外に出し（外在化）、高さ方向の手がかりにもなっている。消すと像が低く・近く感じられる可能性がある。§8.8 の真上の反射 1 本が対策候補。
3. **乾いた Ls/Rs**: 録音の残響が少ない素材（映画のサントラ、ポップス）では Ls/Rs がほぼ無音になり、包まれ感はホールの残響だけになる。アップミックスの「サラウンド」量で調整できる範囲かどうかを試聴で確認する。
4. **既定にするか**: 理想ホールはあくまで比較用の追加プリセットで、既定は §2 の `stalls_center` のまま。試聴の結果で見直す。**要判断。**
